# MS__Chat Android v7

این نسخه مخصوص APK است. سایت وب/Render جداست و نیازی به قرار دادن این پوشه در مخزن Render نیست.

تغییرات این نسخه:
- اصلاح خطای کامپایل `MainActivity.java`.
- رفع منطق پس‌زمینه WebView برای نمایش درست `background.png` در کل صفحه.
- حذف رفتارهای دوره‌ای که می‌توانست نوار پایین را چشمک‌زن کند؛ نوار فقط هنگام نمایش صفحه ورود مخفی می‌شود.
- نام برنامه: `MS__Chat`.
- آیکون برنامه در منابع Android قرار دارد.

ساخت APK در GitHub Actions با JDK 17 و Gradle 8.7 انجام می‌شود.
