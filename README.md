# MS__Chat Android v6

این نسخه فقط یک اصلاح هدفمند برای APK دارد: پس‌زمینه داخل WebView از `html` رندر می‌شود و پس‌زمینه `fixed` حذف شده تا روی Android WebView به‌صورت کامل در تمام ارتفاع صفحه دیده شود. رابط وب و نسخه دسکتاپ تغییر نکرده‌اند.

همان WebView سایت `https://ms-chat-307k.onrender.com/` باز می‌شود و نام برنامه `MS__Chat` و آیکون آن حفظ شده‌اند.

ساخت APK:
1. محتوای این پوشه را در ریشه مخزن `MS-Chat-APK` قرار دهید.
2. `Actions -> Build MS Chat APK -> Run workflow`.
3. از `Artifacts -> MS-Chat-APK` فایل APK را دریافت کنید.

`.env` را وارد این مخزن نکنید.
