# MS__Chat Android v8

این مخزن فقط برای ساخت APK اندروید است و نباید به Render اضافه شود.

## تغییرات v8
- سایت وب دست‌نخورده باقی می‌ماند؛ APK همان وب‌سایت موجود را در WebView باز می‌کند.
- پس‌زمینه در WebView به‌صورت تمام‌صفحه نمایش داده می‌شود.
- هیچ `display`/چیدمان اجباری روی نوار پایین اعمال نمی‌شود؛ فقط اگر نوار پایین در خود وب وجود داشته باشد، هنگام نمایش صفحه ورود با `visibility/opacity` موقتاً پنهان می‌شود و پس از ورود به حالت عادی برمی‌گردد.
- هیچ override عمومی برای `pointer-events` روی دکمه‌ها و فیلدها اعمال نمی‌شود تا کلیک‌های سایت آسیب نبینند.
- کش و تاریخچه هنگام شروع تازه مدیریت می‌شوند تا نسخه‌های قدیمی رابط نمایش داده نشوند.
- نام برنامه: `MS__Chat`

## ساخت APK
در GitHub Actions، workflow با JDK 17 و Gradle 8.7 اجرا می‌شود.
پس از موفقیت، فایل `app-debug.apk` از Artifact با نام `MS-Chat-APK` قابل دریافت است.
